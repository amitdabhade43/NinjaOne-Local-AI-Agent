# Policies and configuration

- Identify the target organization/device and relevant policy type.
- Discover policy list, details, assignment, and override endpoints separately where necessary.
- Compare effective device configuration with intended policy; do not assume policy assignment means every setting is applied.
- Report missing assignments, overrides, and differences with the evidence available.
- Changes to policy assignments or configuration require human approval and a precise affected-target summary.
