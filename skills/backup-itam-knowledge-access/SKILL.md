# Backup, ITAM, knowledge, and access

- Discover the exact resource and endpoint before assuming a feature is available in the tenant/API version.
- For backup, distinguish configured protection, last successful backup, failed job, and restore capability.
- For ITAM, distinguish managed devices from unmanaged assets, software/license records, tags, and relationships.
- For knowledge content, search existing articles before proposing creation or updates.
- For roles and permissions, inspect current access and least-privilege requirements.
- All create/update/assignment operations require approval. Do not claim a feature is supported unless the OpenAPI catalogue and live tenant confirm it.
