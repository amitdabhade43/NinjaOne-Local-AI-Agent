# Automation and scripts

- Search for scripts by name, purpose, platform, and category; inspect details and required variables.
- Confirm the script is the intended approved script and compatible with target OS/device type.
- Resolve every target device ID and validate required script parameters.
- Before execution, show script identity, target count/list, variables, and expected impact.
- Script execution is a write/high-impact operation and requires explicit approval.
- Never invent script IDs or variables. Never claim success until the job/result is verified.
